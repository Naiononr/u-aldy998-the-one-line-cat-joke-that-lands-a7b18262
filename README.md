One joke about cats, one line, 81 characters:

> I told my cat he was adopted. He blinked once, slowly, and I apologised to a cat.

## Why it lands

The setup promises a sentimental moment — telling a pet it's adopted — and the turn flips the power dynamic in a single slow blink. The cat doesn't react with hurt or confusion; it stares the human down, and the human ends up apologising to a cat. No tired puns, no explanation after the punchline, and every word earns its place. It's the kind of line you'd repeat to a friend the same day.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline. Python 3, standard library only.
